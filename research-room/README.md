# Research Room

Collaborative thesis proposal workspace for small student research teams.

Features: account sign-in, invite-code workspace membership, editable proposal sections, tasks and deadlines, meeting agendas and notes, and persistent database storage.

Live app: https://research-room-41f5cr.v2.appdeploy.ai/

The app uses AppDeploy platform SDKs for auth, backend API, and database. The supplied proposal template is editable starter content; confirm official school formatting before submission.
