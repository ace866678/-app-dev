# Research Room

Live collaborative thesis proposal workspace: https://research-room-41f5cr.v2.appdeploy.ai/

The app supports account sign-in, workspace creation and join codes, editable proposal template sections, task assignments and deadlines, and meeting agendas and notes.

The app source is managed in the AppDeploy source snapshot. It uses the platform's injected AppDeploy client/server SDKs for authentication, API routes, and database persistence; replacing those integrations is needed for standalone local hosting.
