# Research Room

A collaborative thesis proposal workspace for student research teams.

## Features
- Sign in with an individual account
- Create a research workspace or join with a private code
- Edit and save thesis proposal sections to the shared database
- Create, assign, update, and delete tasks
- Plan meetings and store shared notes
- Manage the thesis title, institution, and degree program

## Development
The project uses React, Vite, TypeScript, and Lucide icons. The hosted version uses platform-provided AppDeploy SDK integrations for authentication, API routes, and persistent database storage. To run this outside the AppDeploy host, replace those SDK integrations with your own authentication and backend/database provider.
